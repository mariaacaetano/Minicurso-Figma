# Minicurso Pulse — Vue, HTML e CSS

Bem-vindo ao minicurso de criação da página da Pulse.

Neste curso, vamos transformar uma ideia visual em uma landing page responsiva usando Vue, HTML semântico e CSS, passando do planejamento à validação final.

## O que você vai aprender

- Criar um projeto Vue com Vite.
- Organizar uma página em seções semânticas.
- Usar `script setup`, interpolação e `v-for`.
- Estruturar layouts com Flexbox e CSS Grid.
- Trabalhar identidade visual, responsividade e acessibilidade.
- Validar o projeto com o build de produção.

## Projeto do minicurso

Construiremos a página da Pulse com cabeçalho, navegação, seção hero, cards de serviços, chamada para contato e rodapé, adaptados para dispositivos móveis.

## Pré-requisitos

- Node.js em versão LTS;
- Editor de código, como VS Code;
- Conhecimentos básicos de HTML e CSS.

## Como começar

```bash
npm create vite@latest pulse -- --template vue
cd pulse
npm install
npm run dev
```

Ao final, valide a aplicação com:

```bash
npm run build
```
