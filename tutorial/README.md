# Roteiro do tutorial da página Pulse

1. Identificar as seções da página: cabeçalho, hero, serviços, contato e rodapé.
2. Criar a estrutura semântica no template do Vue.
3. Organizar os dados repetidos em arrays e renderizar com `v-for`.
4. Definir tipografia, cores, espaçamento e componentes de botão no CSS.
5. Montar o destaque visual do hero com CSS.
6. Adicionar responsividade para telas menores.
7. Rodar `npm run build` para validar a entrega.
